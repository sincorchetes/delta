title: Backup history
description: See every backup Delta has made.
---

import Shot from '../../components/Shot.astro';

Choose **Backup history** in the Delta window to see all your backups.

<Shot name="history" alt="The Backup history window: a table of backups with their date, age and name." />

Each row shows the **Date**, the **Age** and the **Name** of a backup. **No backups yet** appears until the first one finishes.
If Delta cannot read them, you see **Could not read the backups**.
