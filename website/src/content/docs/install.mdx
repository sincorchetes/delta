## What you need

- **GNOME 46 or newer** (libadwaita 1.5, GTK 4.10) and **Python 3.12 or newer**.
- **BorgBackup**, the program that stores the copies.
- **A keyring**, such as GNOME Keyring, to keep the passphrase of your backups.
- **nautilus-python**, so Files shows **Restore Previous Version…**. Delta works without it, but only from its own window.
- **The GStreamer plugins** (base and good), for the preview of videos and audio in the versions window. The packages recommend
  them; without them, previewing one of those files stops Delta, because GTK ends the whole program.
- A **systemd user session**, which runs the scheduled backups. Every GNOME desktop on a mainstream distribution has one.

<Aside type="note" title="Where Delta is today">
Delta is published in a **repository for each distribution**, built by the openSUSE Build Service: add it once, and your
package manager installs Delta and keeps it up to date. Fedora (43 and 44), Rocky Linux 10, AlmaLinux 10, openSUSE
Tumbleweed, Debian 13 and Ubuntu (26.04 and 26.10) have one, and Arch Linux has the AUR. For any other distribution, or
version, install the Flatpak, build the package yourself, use Nix, or build from source.
</Aside>

## Install from the repository

Add the repository of your distribution once, and install **`delta-backup`**. The packages are signed: your package
manager asks you to trust the key the first time. The package brings what Delta needs (BorgBackup, the keyring, the
Python bindings) as its own dependencies.

<Tabs>
  <TabItem label="Fedora">
    ```sh
    sudo dnf config-manager addrepo --from-repofile=https://download.opensuse.org/repositories/home:/sincorchetes:/delta/Fedora_44/home:sincorchetes:delta.repo
    sudo dnf install delta-backup
    ```
    On Fedora 43, use `Fedora_43` in the address.
  </TabItem>
  <TabItem label="Rocky, AlmaLinux">
    BorgBackup comes from EPEL, so enable it first. On AlmaLinux, use `AlmaLinux_10` in the address instead of `RockyLinux_10`.

    ```sh
    sudo dnf install epel-release
    sudo dnf config-manager --add-repo https://download.opensuse.org/repositories/home:/sincorchetes:/delta/RockyLinux_10/home:sincorchetes:delta.repo
    sudo dnf install delta-backup
    ```
  </TabItem>
  <TabItem label="openSUSE Tumbleweed">
    ```sh
    sudo zypper addrepo https://download.opensuse.org/repositories/home:/sincorchetes:/delta/openSUSE_Tumbleweed/home:sincorchetes:delta.repo
    sudo zypper refresh
    sudo zypper install delta-backup
    ```
  </TabItem>
  <TabItem label="Debian, Ubuntu">
    The repository is signed with a key that you add first. This is for Debian 13. On Ubuntu, use `xUbuntu_26.04` or
    `xUbuntu_26.10` in the two addresses instead of `Debian_13`.

    ```sh
    sudo apt install curl gnupg ca-certificates
    sudo install -d /etc/apt/keyrings
    curl -fsSL https://download.opensuse.org/repositories/home:/sincorchetes:/delta/Debian_13/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/delta.gpg
    echo "deb [signed-by=/etc/apt/keyrings/delta.gpg] https://download.opensuse.org/repositories/home:/sincorchetes:/delta/Debian_13/ /" | sudo tee /etc/apt/sources.list.d/delta.list
    sudo apt update
    sudo apt install delta-backup
    ```
  </TabItem>
  <TabItem label="Arch Linux">
    From the AUR, with your AUR helper:

    ```sh
    yay -S delta-backup
    ```
  </TabItem>
</Tabs>

Then log out and back in, so Files loads the extension and your session finds the Delta service.

## Build the package yourself

Where there is no repository (for example Ubuntu 24.04, or another version or distribution), or if you prefer to build it, each package is named
`delta-backup` and installs the same files as the source build, with your distribution's own dependencies. Get the source first:

```sh
git clone https://github.com/sincorchetes/delta.git && cd delta
```

<Tabs>
  <TabItem label="Fedora, Rocky, Alma">
    On Rocky Linux and AlmaLinux 10, enable EPEL and CRB first: `sudo dnf install epel-release && sudo dnf config-manager --set-enabled crb`.

    ```sh
    sudo dnf builddep packaging/rpm/delta-backup.spec
    mkdir -p ~/rpmbuild/SOURCES
    git archive --format=tar.gz --prefix=delta-0.3.0/ -o ~/rpmbuild/SOURCES/delta-0.3.0.tar.gz HEAD
    rpmbuild -ba packaging/rpm/delta-backup.spec
    sudo dnf install ~/rpmbuild/RPMS/noarch/delta-backup-*.rpm
    ```
  </TabItem>
  <TabItem label="openSUSE">
    ```sh
    sudo zypper install rpm-build $(rpmspec -q --buildrequires packaging/rpm/delta-backup.spec)
    mkdir -p ~/rpmbuild/SOURCES
    git archive --format=tar.gz --prefix=delta-0.3.0/ -o ~/rpmbuild/SOURCES/delta-0.3.0.tar.gz HEAD
    rpmbuild -ba packaging/rpm/delta-backup.spec
    sudo zypper install ~/rpmbuild/RPMS/noarch/delta-backup-*.rpm
    ```
  </TabItem>
  <TabItem label="Debian, Ubuntu">
    ```sh
    sudo apt install build-essential devscripts equivs
    sudo mk-build-deps -ir -t "apt-get -y" debian/control
    dpkg-buildpackage -us -uc -b
    sudo apt install ../delta-backup_*_all.deb
    ```
  </TabItem>
  <TabItem label="Arch Linux">
    ```sh
    cd packaging/arch
    makepkg -si
    ```
  </TabItem>
</Tabs>

Then log out and back in, so Files loads the extension and your session finds the Delta service.

## Install the Flatpak

The Flatpak works on any distribution with Flatpak and a GNOME desktop. Download the `.flatpak` file from the
[latest release](https://github.com/sincorchetes/delta/releases/latest) and install it. Flatpak fetches the GNOME runtime
from Flathub by itself if you do not have it.

```sh
flatpak install --user ./delta-*.flatpak
flatpak run io.github.sincorchetes.Delta
```

It is not in Flathub, so it does not update by itself: to update, install the bundle of the new release the same way. Install
the Flatpak **or** the native package, not both: they share the same service name, and the window would talk to whichever
service started first.

## Install with Nix

### On NixOS

The NixOS module installs Delta, **nautilus-python** (for the right-click menu of Files), and sets up what a session has to
find: the user service and its timer, the D-Bus service, the settings schema, the manual and the translations.

With flakes, in the flake of your system:

```nix
{
  inputs.delta.url = "github:sincorchetes/delta";
  inputs.delta.inputs.nixpkgs.follows = "nixpkgs";

  outputs = { nixpkgs, delta, ... }: {
    nixosConfigurations.your-host = nixpkgs.lib.nixosSystem {
      modules = [
        ./configuration.nix
        delta.nixosModules.default
        { services.delta.enable = true; }
      ];
    };
  };
}
```

Without flakes, in your `configuration.nix`:

```nix
{ ... }:
let
  delta = builtins.fetchTarball "https://github.com/sincorchetes/delta/archive/main.tar.gz";
in
{
  imports = [ "${delta}/nix/nixos.nix" ];
  services.delta.enable = true;
}
```

Then run `sudo nixos-rebuild switch` and log out and back in. To keep the version fixed, point the address at a tag or a commit
and add its `sha256` to `fetchTarball`.

<Aside type="caution" title="One module only">
Use the NixOS module **or** the Home Manager one, not both: they install the same package and declare the same units, and the
ones that Home Manager links in your home folder win over the system's.
</Aside>

### With Home Manager

For any distribution with Nix, and for NixOS if you would rather keep it in your user configuration.

<Steps>

1. Add Delta as an input of your flake and import its module:

   ```nix
   {
     inputs.delta.url = "github:sincorchetes/delta";

     # In your Home Manager configuration:
     imports = [ inputs.delta.homeManagerModules.default ];
     services.delta.enable = true;
   }
   ```

2. Apply your configuration (`home-manager switch`).
3. Install **nautilus-python** system-wide. Home Manager cannot do it for you.
4. Log out and back in so Files loads the extension.

</Steps>

## Build it from source

<Steps>

1. Install the build tools and libraries: Meson, Ninja, GLib, GTK 4, libadwaita, PyGObject, libsecret and BorgBackup.
2. Build and install:

   ```sh
   meson setup build --prefix=$HOME/.local
   meson compile -C build
   meson install -C build
   ```

3. Log out and back in.

</Steps>

## Check that it works

Open **Delta** from the Activities overview. If the window asks you to set up backups, it is ready:
continue with [your first backup](../first-backup/).

<Aside type="caution" title="The Flatpak does not have the folder view">
The Flatpak has the Delta window with versions, preview, folder browser and restore. It cannot offer
**Browse as a folder**, because Files runs outside the sandbox and cannot see a folder mounted inside it.
See [How Delta works](../how-it-works/#two-ways-to-install-it).
</Aside>

## Right-click in Files with the Flatpak

Files loads its extensions from your computer, never from a Flatpak, so the Flatpak cannot add **Restore Previous Version…** to the
right-click menu by itself. If you want it, install one small file next to Files. It does not need the rest of Delta: it opens the Flatpak.

1. Install **nautilus-python** from your distribution. For example, `sudo dnf install nautilus-python` on Fedora,
   `sudo pacman -S nautilus-python` on Arch, `sudo apt install python3-nautilus` on Debian and Ubuntu.
2. Put the extension where Files looks for it, and restart Files:

   ```sh
   mkdir -p ~/.local/share/nautilus-python/extensions
   curl -fsSL -o ~/.local/share/nautilus-python/extensions/delta_extension.py \
     https://raw.githubusercontent.com/sincorchetes/delta/main/src/nautilus/delta_extension.py
   nautilus -q
   ```

<Aside type="note">
The entry is in English, because the translations stay inside the Flatpak. The **Backup** column and the emblems depend on settings
that the Flatpak also keeps inside its sandbox, so they can be less precise than in the native install. The entry itself,
which is what opens the **Previous versions** window, works the same.
</Aside>
