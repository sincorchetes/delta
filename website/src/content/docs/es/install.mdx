## Qué necesitas

- **GNOME 46 o posterior** (libadwaita 1.5, GTK 4.10) y **Python 3.12 o posterior**.
- **BorgBackup**, el programa que guarda las copias.
- **Un llavero**, como GNOME Keyring, para guardar la contraseña de tus copias.
- **nautilus-python**, para que Archivos muestre **Restaurar versión anterior…**. Delta funciona sin él, pero solo desde su propia ventana.
- **Los plugins de GStreamer** (base y good), para la vista previa de vídeos y audio en la ventana de versiones. Los paquetes los
  recomiendan; sin ellos, previsualizar uno de esos archivos cierra Delta, porque GTK termina todo el programa.
- Una **sesión de usuario de systemd**, que ejecuta las copias programadas. Todo escritorio GNOME de una distribución común la tiene.

<Aside type="note" title="Dónde está Delta hoy">
Delta se publica en un **repositorio para cada distribución**, construido por el openSUSE Build Service: lo añades una vez
y tu gestor de paquetes instala Delta y lo mantiene actualizado. Fedora (43 y 44), Rocky Linux 10, AlmaLinux 10, openSUSE
Tumbleweed, Debian 13 y Ubuntu (26.04 y 26.10) tienen el suyo, y Arch Linux tiene el AUR. Para cualquier otra distribución,
o versión, instala el Flatpak, compila el paquete tú, usa Nix o compila desde el código fuente.
</Aside>

## Instalar desde el repositorio

Añade una vez el repositorio de tu distribución e instala **`delta-backup`**. Los paquetes están firmados: tu gestor de
paquetes te pide que confíes en la clave la primera vez. El paquete trae lo que Delta necesita (BorgBackup, el llavero y los
enlaces de Python) como dependencias propias.

<Tabs>
  <TabItem label="Fedora">
    ```sh
    sudo dnf config-manager addrepo --from-repofile=https://download.opensuse.org/repositories/home:/sincorchetes:/delta/Fedora_44/home:sincorchetes:delta.repo
    sudo dnf install delta-backup
    ```
    En Fedora 43, usa `Fedora_43` en la dirección.
  </TabItem>
  <TabItem label="Rocky, AlmaLinux">
    BorgBackup viene de EPEL, así que actívalo antes. En AlmaLinux, usa `AlmaLinux_10` en la dirección en lugar de `RockyLinux_10`.

    ```sh
    sudo dnf install epel-release
    sudo dnf config-manager --add-repo https://download.opensuse.org/repositories/home:/sincorchetes:/delta/RockyLinux_10/home:sincorchetes:delta.repo
    sudo dnf install delta-backup
    ```
  </TabItem>
  <TabItem label="openSUSE Tumbleweed">
    ```sh
    sudo zypper addrepo https://download.opensuse.org/repositories/home:/sincorchetes:/delta/openSUSE_Tumbleweed/home:sincorchetes:delta.repo
    sudo zypper refresh
    sudo zypper install delta-backup
    ```
  </TabItem>
  <TabItem label="Debian, Ubuntu">
    El repositorio está firmado con una clave que se añade primero. Esto es para Debian 13. En Ubuntu, usa `xUbuntu_26.04` o
    `xUbuntu_26.10` en las dos direcciones en lugar de `Debian_13`.

    ```sh
    sudo apt install curl gnupg ca-certificates
    sudo install -d /etc/apt/keyrings
    curl -fsSL https://download.opensuse.org/repositories/home:/sincorchetes:/delta/Debian_13/Release.key | sudo gpg --dearmor -o /etc/apt/keyrings/delta.gpg
    echo "deb [signed-by=/etc/apt/keyrings/delta.gpg] https://download.opensuse.org/repositories/home:/sincorchetes:/delta/Debian_13/ /" | sudo tee /etc/apt/sources.list.d/delta.list
    sudo apt update
    sudo apt install delta-backup
    ```
  </TabItem>
  <TabItem label="Arch Linux">
    Desde el AUR, con tu ayudante del AUR:

    ```sh
    yay -S delta-backup
    ```
  </TabItem>
</Tabs>

Después, cierra la sesión y vuelve a entrar, para que Archivos cargue la extensión y tu sesión encuentre el servicio de Delta.

## Compilar el paquete tú mismo

Donde no hay repositorio (por ejemplo, Ubuntu 24.04, u otra versión o distribución), o si prefieres compilarlo, cada paquete se llama `delta-backup` e
instala los mismos archivos que la compilación desde el código fuente, con las dependencias propias de tu distribución. Primero, descarga el código:

```sh
git clone https://github.com/sincorchetes/delta.git && cd delta
```

<Tabs>
  <TabItem label="Fedora, Rocky, Alma">
    En Rocky Linux y AlmaLinux 10, activa antes EPEL y CRB: `sudo dnf install epel-release && sudo dnf config-manager --set-enabled crb`.

    ```sh
    sudo dnf builddep packaging/rpm/delta-backup.spec
    mkdir -p ~/rpmbuild/SOURCES
    git archive --format=tar.gz --prefix=delta-0.1.2/ -o ~/rpmbuild/SOURCES/delta-0.1.2.tar.gz HEAD
    rpmbuild -ba packaging/rpm/delta-backup.spec
    sudo dnf install ~/rpmbuild/RPMS/noarch/delta-backup-*.rpm
    ```
  </TabItem>
  <TabItem label="openSUSE">
    ```sh
    sudo zypper install rpm-build $(rpmspec -q --buildrequires packaging/rpm/delta-backup.spec)
    mkdir -p ~/rpmbuild/SOURCES
    git archive --format=tar.gz --prefix=delta-0.1.2/ -o ~/rpmbuild/SOURCES/delta-0.1.2.tar.gz HEAD
    rpmbuild -ba packaging/rpm/delta-backup.spec
    sudo zypper install ~/rpmbuild/RPMS/noarch/delta-backup-*.rpm
    ```
  </TabItem>
  <TabItem label="Debian, Ubuntu">
    ```sh
    sudo apt install build-essential devscripts equivs
    sudo mk-build-deps -ir -t "apt-get -y" debian/control
    dpkg-buildpackage -us -uc -b
    sudo apt install ../delta-backup_*_all.deb
    ```
  </TabItem>
  <TabItem label="Arch Linux">
    ```sh
    cd packaging/arch
    makepkg -si
    ```
  </TabItem>
</Tabs>

Después, cierra la sesión y vuelve a entrar, para que Archivos cargue la extensión y tu sesión encuentre el servicio de Delta.

## Instalar el Flatpak

El Flatpak funciona en cualquier distribución con Flatpak y un escritorio GNOME. Descarga el archivo `.flatpak` de la
[última versión](https://github.com/sincorchetes/delta/releases/latest) e instálalo. Flatpak descarga por sí mismo el runtime
de GNOME desde Flathub si no lo tienes.

```sh
flatpak install --user ./delta-*.flatpak
flatpak run io.github.sincorchetes.Delta
```

No está en Flathub, así que no se actualiza solo: para actualizar, instala del mismo modo el bundle de la nueva versión. Instala
el Flatpak **o** el paquete nativo, no los dos: comparten el nombre del servicio, y la ventana hablaría con el servicio que
arranque primero.

## Instalar con Nix

### En NixOS

El módulo de NixOS instala Delta, **nautilus-python** (para el menú del clic derecho de Archivos) y deja preparado lo que una
sesión tiene que encontrar: el servicio de usuario y su temporizador, el servicio de D-Bus, el esquema de ajustes, el manual y
las traducciones.

Con flakes, en el flake de tu sistema:

```nix
{
  inputs.delta.url = "github:sincorchetes/delta";
  inputs.delta.inputs.nixpkgs.follows = "nixpkgs";

  outputs = { nixpkgs, delta, ... }: {
    nixosConfigurations.tu-equipo = nixpkgs.lib.nixosSystem {
      modules = [
        ./configuration.nix
        delta.nixosModules.default
        { services.delta.enable = true; }
      ];
    };
  };
}
```

Sin flakes, en tu `configuration.nix`:

```nix
{ ... }:
let
  delta = builtins.fetchTarball "https://github.com/sincorchetes/delta/archive/main.tar.gz";
in
{
  imports = [ "${delta}/nix/nixos.nix" ];
  services.delta.enable = true;
}
```

Después ejecuta `sudo nixos-rebuild switch` y cierra la sesión y vuelve a entrar. Para dejar fija la versión, apunta la dirección
a una etiqueta o a un commit y añade su `sha256` a `fetchTarball`.

<Aside type="caution" title="Un solo módulo">
Usa el módulo de NixOS **o** el de Home Manager, no los dos: instalan el mismo paquete y declaran las mismas unidades, y las que
Home Manager enlaza en tu carpeta personal tienen prioridad sobre las del sistema.
</Aside>

### Con Home Manager

Para cualquier distribución con Nix, y para NixOS si prefieres dejarlo en tu configuración de usuario.

<Steps>

1. Añade Delta como entrada de tu flake e importa su módulo:

   ```nix
   {
     inputs.delta.url = "github:sincorchetes/delta";

     # En tu configuración de Home Manager:
     imports = [ inputs.delta.homeManagerModules.default ];
     services.delta.enable = true;
   }
   ```

2. Aplica tu configuración (`home-manager switch`).
3. Instala **nautilus-python** en todo el sistema. Home Manager no puede hacerlo por ti.
4. Cierra la sesión y vuelve a entrar para que Archivos cargue la extensión.

</Steps>

## Compilar desde el código fuente

<Steps>

1. Instala las herramientas y bibliotecas: Meson, Ninja, GLib, GTK 4, libadwaita, PyGObject, libsecret y BorgBackup.
2. Compila e instala:

   ```sh
   meson setup build --prefix=$HOME/.local
   meson compile -C build
   meson install -C build
   ```

3. Cierra la sesión y vuelve a entrar.

</Steps>

## Comprueba que funciona

Abre **Delta** desde la vista de Actividades. Si la ventana te pide configurar las copias, está listo:
sigue con [tu primera copia](../first-backup/).

<Aside type="caution" title="El Flatpak no tiene la vista como carpeta">
El Flatpak tiene la ventana de Delta con versiones, vista previa, explorador de carpetas y restauración. No puede ofrecer
**Examinar como carpeta**, porque Archivos se ejecuta fuera del sandbox y no ve una carpeta montada dentro de él.
Consulta [Cómo funciona Delta](../how-it-works/#dos-formas-de-instalarlo).
</Aside>

## Clic derecho en Archivos con el Flatpak

Archivos carga sus extensiones desde tu equipo, nunca desde un Flatpak, así que el Flatpak no puede añadir por sí solo
**Restaurar versión anterior…** al menú del clic derecho. Si lo quieres, instala un pequeño archivo junto a Archivos. No necesita el resto
de Delta: abre el Flatpak.

1. Instala **nautilus-python** desde tu distribución. Por ejemplo, `sudo dnf install nautilus-python` en Fedora,
   `sudo pacman -S nautilus-python` en Arch, `sudo apt install python3-nautilus` en Debian y Ubuntu.
2. Pon la extensión donde Archivos la busca y reinicia Archivos:

   ```sh
   mkdir -p ~/.local/share/nautilus-python/extensions
   curl -fsSL -o ~/.local/share/nautilus-python/extensions/delta_extension.py \
     https://raw.githubusercontent.com/sincorchetes/delta/main/src/nautilus/delta_extension.py
   nautilus -q
   ```

<Aside type="note">
La entrada sale en inglés, porque las traducciones se quedan dentro del Flatpak. La columna **Copia** y los emblemas dependen de ajustes
que el Flatpak también guarda dentro de su sandbox, así que pueden ser menos precisos que en la instalación nativa. La entrada en sí,
que es la que abre la ventana **Versiones anteriores**, funciona igual.
</Aside>
